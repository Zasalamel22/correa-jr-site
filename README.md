# Correa Jr

Static one-page site for Correa Jr, videographer and photographer in Moscow. Plain HTML, CSS and JavaScript, no build step. Served with GitHub Pages from the root of `main`.

Source and design notes live in the private project repository.

Clients download their files in the "Клиентам" section: the photographer shares a Yandex Disk folder and sends the code from its link; `enviar.html` prepares that message.
